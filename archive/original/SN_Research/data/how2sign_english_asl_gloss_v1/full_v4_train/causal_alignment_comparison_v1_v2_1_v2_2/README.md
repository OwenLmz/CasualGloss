# Unified v1 / v2.1 / v2.2 Locked-500 Comparison

This directory contains a paired comparison of the three causal-alignment systems on the same 500 parent sentences.

Scientific boundaries:

- English source text, source tokens, parent IDs, and pseudo-gloss references must match exactly across versions.
- The gloss reference is generated by Qwen and is not expert-verified gold ASL.
- Standard reference-length AL and LAAL are recomputed from per-token WRITE positions.
- Confidence intervals use a deterministic paired parent-level percentile bootstrap.
- Omission cases are diagnostic associations and do not establish that early commitment caused an error.

Core outputs:

- `reports/unified_locked500_comparison.json`
- `reports/unified_locked500_summary.tsv`
- `reports/unified_locked500_comparison.png`
- `reports/unified_locked500_comparison.pdf`
- `cases/selected_case_studies.jsonl`
- `cases/selected_case_studies.md`
