# Reuse Audit

## Rejected as scientific evidence

### `professor_feedback_experiments_20260912/learned_baseline`

This run is not a direct TransLLaMA training reproduction. Its stage A and
stage B training both consume `causal_alignment_v1_corrected_full` action
manifests. Those labels were generated by the earlier CausalGloss alignment
pipeline, rather than independently by the official TransLLaMA SimAlign and
prefix-sampling construction. Its adapter and locked-test results are excluded
from the new baseline.

### `transllama_style_wait_k_inference_v1`

This run applies a TransLLaMA-style inference controller to already-trained
v1 and v2.2 action models. Its own README states that it does not retrain the
models and is not a full reproduction of TransLLaMA training. Its results are
excluded. Only generic rollout and metric utilities may be reused after tests.

### `transllama_exact_wait_k_paper_update_20260910`

These reports compare CausalGloss with the inference-only v1 k=1 point. They
do not supply the missing independently trained learned adaptive baseline and
are excluded from the new evidence base.

## Allowed reusable assets

- Raw source text and target pseudo-gloss fields from the existing pair files.
- Existing parent-level train, validation, and locked-test IDs.
- Qwen2.5-7B model cache and its pinned revision.
- Fine-tuning-1 adapter as the common checkpoint before policy-specific work.
- Generic PEFT loading, distributed training, logging, metric, rollout-record,
  and bootstrap code after behavior is covered by new tests.

## Components to rebuild independently

- Pure SimAlign alignment and WAIT insertion.
- Aligned-prefix sampling and target construction.
- Qwen chat formatting and exact target-only loss masking.
- Learned WAIT/WRITE generation and state transitions.
- Learning-rate screening, checkpoint selection, and three-seed runners.
- New provenance, checksums, validation reports, and locked-test reports.

## Frozen task-specific adaptations

- Use the manifest's shared source/gloss token lists for SimAlign rather than
  re-tokenizing gloss strings with NLTK. This avoids splitting task tokens such
  as `CAN'T` and keeps the learned baseline on the same output space as
  CausalGloss.
- Append target-side WAIT actions when a concise gloss sequence ends before
  the English source. This supplies READ supervision only; it never imports a
  gloss, timing label, or action from the existing CausalGloss manifests.

## Token decision

Qwen tokenization was inspected at the pinned revision. `@@` is one existing
token, while `<WAIT>` is three tokens. The internal WAIT symbol will therefore
be `@@`, displayed as `<WAIT>` in descriptions and normalized to the READ
action in rollouts. Native EOS represents termination.
